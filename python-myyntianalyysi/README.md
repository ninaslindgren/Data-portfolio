# Python-myyntianalyysi

Pythonilla toteutettu data-analyysiprojekti kuvitteellisen verkkokaupan myyntidatasta.

## Projektin tavoite

Tavoitteena on analysoida yrityksen myyntiä ja kannattavuutta sekä tunnistaa parhaiten menestyvät tuotteet, tuoteryhmät ja myyntikanavat.

## Analyysissä tarkastellaan

- kokonaismyyntiä ja kokonaiskatetta
- 10 myydyintä tuotetta
- myynnin kehitystä kuukausittain
- katetta tuoteryhmittäin
- myyntiä myyntikanavittain

## Käytetyt työkalut

- Python
- Pandas
- Matplotlib
- Google Colab

## Keskeisiä havaintoja

- Kokonaismyynti oli 137 394,05 €.
- Kokonaiskate oli 69 474,55 €.
- Älykello oli myynniltään paras tuote.
- Elektroniikka oli kannattavin tuoteryhmä.
- Sähköposti oli suurin myyntikanava.
- Maaliskuu 2026 oli tarkastelujakson paras myyntikuukausi.

## Tiedostot

- `Python-myyntianalyysi.ipynb` – analyysin Python-koodi, tulokset ja visualisoinnit
- `python_myyntianalyysi_data.csv` – analyysissä käytetty kuvitteellinen aineisto
